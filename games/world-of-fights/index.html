📖 Cum instalezi:

  1. Apasă butonul DOWNLOAD GAME de mai sus
  2. Dă dublu-click pe WorldOfFights_Final.jar descărcat
  3. Dacă nu pornește, rulează din CMD: java -Xmx512m -jar WorldOfFights_Final.jar
  4. Login cu orice nume și parolă (cont se creează automat)
  5. Apasă "JOIN" și începe lupta!
