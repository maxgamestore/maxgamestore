🎧 Support Center

❓ How do I download the game?
Create an account, login, then go to Games → World Of Fights → Download.
❓ The game won't start!
Make sure you have Java 17+ installed. Download from java.com.
❓ Can't connect to server?
Check the server address on the game page. Make sure the host is online.
